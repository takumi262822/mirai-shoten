== 概要

本書は MIRAI SHOTEN（未来商店商材）全体で使用する共通ユーティリティの仕様を記載します。
XSS対策・入力バリデーション・UIコンポーネントを対象とします。

---

== 1. XSSProtection クラス

=== 所在

`src/utils/xss.js`

=== 責務

DOM への文字列反映前に HTML 特殊文字をエスケープし、XSS 攻撃を防ぐ。
全角英数字の半角正規化も担う。

=== 静的メソッド

==== escape(value)

文字列内の HTML 特殊文字をエンティティに置換して返す。

[cols="1,3", options="header"]
|===
|引数
|説明

|`value`
|任意の値。`null` / `undefined` の場合は空文字を返す。
|===

*変換表:*

[cols="1,1", options="header"]
|===
|入力文字
|変換後エンティティ

|`&`
|`&amp;`

|`<`
|`&lt;`

|`>`
|`&gt;`

|`"`
|`&quot;`

|`'`
|`&#39;`
|===

*実装方針:*
- 変換ルールはオブジェクトで管理し、`replace(/[&<>"']/g, ...)` で一括処理する
- `null` / `undefined` は先に空文字変換して処理する

---

==== normalizeFullWidthAscii(value)

全角英数字・記号を半角に変換し、不要なスペースを除去して返す。

[cols="1,3", options="header"]
|===
|引数
|説明

|`value`
|任意の文字列。falsy な場合は空文字を返す。
|===

*変換ルール:*

[cols="2,2", options="header"]
|===
|変換前
|変換後

|全角英大文字 `Ａ-Ｚ`
|半角英大文字 `A-Z`

|全角英小文字 `ａ-ｚ`
|半角英小文字 `a-z`

|全角数字 `０-９`
|半角数字 `0-9`

|全角 `＠`・`．`
|半角 `@` ・ `.`

|全角長音 `ー`
|半角ハイフン `-`

|半角スペース・全角スペース `\u3000`
|（削除）
|===

*実装方針:*
- 文字コード差分 `0xFEE0` を利用して全角→半角変換する
- `ー`（U+30FC）のみ個別に `-` へ変換する
- スペース・全角スペースを `replace` で空文字削除する

== 2. Validator クラス

=== 所在

`src/utils/validator.js`

=== 責務

氏名・フリガナ・電話番号・メールアドレス・郵便番号の形式チェックを行う。

=== 共通定数

[cols="1,3", options="header"]
|===
|定数名
|内容

|`safeNameRegex`
|氏名許可文字パターン。半角英字・スペース・ひらがな・カタカナ・漢字・和文記号を許可。`/^[a-zA-Z\s\u3040-\u309f\u30a0-\u30ff\u4e00-\u9faf\u3000-\u303f]+$/`
|===

=== 静的メソッド

==== isRequired(value)

値が空でないか（必須チェック）を検証する。

*判定条件:* `String(value).trim()` が空でないこと

*戻り値:* `true` / `false`

---

==== isSafeText(value)

値が `safeNameRegex` に一致する安全な文字列かを検証する。

*判定条件:* `safeNameRegex.test(String(value))` が `true`

*戻り値:* `true` / `false`

---

==== hasNumber(value)

値に数字が含まれるかを検証する。

*判定条件:* `/\d/.test(String(value))`

*戻り値:* `true` / `false`

---

==== isKana(value)

値が全角カタカナ（フリガナ）のみで構成されているかを検証する。

*判定条件:* `/^[ァ-ヶー\s]+$/.test(String(value))`

*戻り値:* `true` / `false`

---

==== isTel(value)

電話番号の形式を検証する。

*判定条件:*
. ハイフン `-` を除去する
. 除去後が `/^\d{10,11}$/` に一致すること

*戻り値:* `true` / `false`

---

==== isEmail(value)

メールアドレスの形式を検証する。

*判定条件:* RFC準拠の正規表現 `/^[a-zA-Z0-9.!#$%&'*+/=?^_`{|}~-]+@[a-zA-Z0-9-]+(?:\.[a-zA-Z0-9-]+)*$/` に一致すること

*戻り値:* `true` / `false`

---

==== isZip(value)

郵便番号の形式を検証する。

*判定条件:* `/^\d{3}-?\d{4}$/.test(String(value))`（ハイフンは省略可）

*戻り値:* `true` / `false`

== 4. 使用上の共通ルール

. ユーザー入力値は必ず `XSSProtection.escape()` を通してから DOM に反映する
. フォーム送信前に `Validator` クラスを経由してバリデーションを行う
. 全角入力フォームは `normalizeFullWidthAscii()` で正規化してから保存・検証する
. localStorage への直接読み書きは `src/core/cart-service.js` 経由で行い、他所で直接操作しない

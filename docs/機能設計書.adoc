== クラス設計

=== Main（src/core/main.js）

[cols="2,1,4", options="header"]
|===
|メソッド
|可視性
|処理内容

|constructor()
|public
|現在のページ名を URL から取得し、StyleManager・Header・Footer を初期化する

|init()
|public
|Footer.setYear() 後、ページ名に応じて各 initXxxPage() を分岐呼び出しする

|initNavigation()
|public
|.js-nav 要素のクリックで AppConstants.allowedPaths を検証し、許可パスのみ遷移する。マイページはログイン入力チェックを追加する

|initHomePage()
|public
|トップページ（商品一覧）の描画と「カートに追加」イベントを設定する

|initProductPage()
|public
|CodeDefinitions.productsByPage で商品定義を取得し、詳細表示と「カートに追加」イベントを設定する

|initCartPage()
|public
|localStorage からカートを読み込み、UIComponents.renderCart() で描画する

|initCheckoutPage()
|public
|カート内容を購入フォームに表示し、送信時にバリデーションを実行して localStorage に注文を保存する

|initContactPage()
|public
|問い合わせフォームの入力値を sessionStorage に保存し確認画面へ遷移する

|initContactConfirmPage()
|public
|sessionStorage から入力値を復元して確認画面に表示する

|===

=== CartService（src/core/cart-service.js）

[cols="2,1,4", options="header"]
|===
|メソッド
|可視性
|処理内容

|normalizeQuantity(value)
|static
|文字列数量を parseInt で変換し、1 未満の場合は 1 にクランプする

|calculateTotal(cart)
|static
|カート全アイテムの price × quantity を合計して返す

|===

== ページ遷移フロー

[source]
----
1. index.html（商品一覧）
   └─ カートに追加 → localStorage 保存
2. hokkori-mug.html / aroma-candle.html / organic-linen.html（商品詳細）
   └─ カートに追加 → localStorage 保存
3. cart.html（カート確認）
   └─ 購入へ進む → checkout.html
4. checkout.html（購入情報入力）
   └─ 送信 → バリデーション → adminOrders に保存 → checkout-complete.html
5. contact.html → contact-confirm.html → contact-complete.html
----

== セキュリティ考慮事項

* XSS: 全 DOM への動的テキスト出力は XSSProtection.escape() 経由の textContent を使用
* パス検証: ナビゲーション遷移先は allowedPaths による許可リスト方式で制御
* 入力検証: 購入フォームは Validator で全フィールドを submit 前に検証
